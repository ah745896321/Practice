ZSet = sorted set

Redis提供ZSET功能  可快速排序

寫入成本			= O(log n)
查詢成本            = O(log n)

實作概念

Skip List
具備多層索引

每筆資料寫入時，50%機會加入上一層的索引，直到不加入。

每筆資料查詢時，由最上層查詢範圍(最上層索引數最少，因為索引經過排序，逐層往下可逐漸縮小數字範圍)

對比
功能		維護ZSET     維護ZSET(Skip List)
查詢		O(n)		  O(log n)
寫入		O(n)          O(log n)
取前 N 名	O(n)          O(log n + N)
記憶體		1×			   ~2×
